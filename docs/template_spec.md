# Excel 範本格式說明（12監看分頁）

來源檔案：`data/excel/template.xlsx`（要填寫的檔案）、`data/excel/example.xlsx`（2026/10/26 歷史範例，僅供格式參考）。
兩份檔案的「12監看」分頁版面、合併儲存格、欄位配置完全相同，差異只在 C1 的日期與 F3 的說明文字、以及 example.xlsx 裡已經填好的範例資料。

- 分頁名稱：`12監看`
- 使用範圍：`A1:V64`（V 欄無資料，實際有效欄為 A–U）

## 1. 版面（第 1–4 列為表頭）

| 儲存格（合併範圍） | 內容 |
|---|---|
| `A1:B1` | 標籤文字「監看日期： 」 |
| `C1:E1` | 日期值（datetime，例：2026-11-06 / 2026-10-26） |
| `F1:J1` | 「時段：12午間新聞 監看人員：」 |
| `A3` | 「主播」（未合併，單獨一格，本次不填） |
| `F3:U3` | 說明文字： |
| | - template.xlsx：「本次影片 2026/11/06，僅填 12:00–12:59 四台五字標；收視率免填。」 |
| | - example.xlsx：「2026/10/26 歷史填寫範例，僅供格式與寫法參考，非本次影片答案。」 |
| `Row2` | 五個電視台名稱（各自佔 4 欄的第一欄，未合併但視覺上對齊自己的區塊）：B2=三立、F2=TVBS-N、J2=東森、N2=民視、R2=華視；其餘欄（A30/M30/A4+ 三欄）內容都是「收視率」 |
| `Row4` | 每個電視台區塊的子欄位標題：五字標 / A30 / M30 / A4+（各台固定重複這四個） |

## 2. 時間欄（A 欄）

- `A4` = 標題「時間」
- `A5:A64` = 60 列，值為純整數 `1200, 1201, 1202 … 1259`（HHMM 格式的數字，不是 Excel 時間型別，`number_format` 為 `General`）
- **每一列代表 1 分鐘**，對應 12:00–12:59 整個小時，逐分鐘列出，沒有跳列或合併。

## 3. 四台（＋三立）五字標欄位對照

每個電視台固定佔用連續 4 欄：`[五字標, A30, M30, A4+]`。本次任務只需填寫「五字標」欄，A30/M30/A4+ 為收視率，依規則不用填。

| 電視台 | 區塊欄位 | 五字標欄（要填的欄） | 收視率欄（不填） |
|---|---|---|---|
| 三立（SET，本台自身，不在填寫範圍內） | B–E | **B** | C, D, E |
| TVBS-N | F–I | **F** | G, H, I |
| 東森（EBC） | J–M | **J** | K, L, M |
| 民視（FTV） | N–Q | **N** | O, P, Q |
| 華視（CTS） | R–U | **R** | S, T, U |

對應到任務裡的四支影片檔名：`tvbs.mp4` → F 欄、`ebc.mp4` → J 欄、`ftv.mp4` → N 欄、`cts.mp4` → R 欄。
三立（B 欄）是三立自家節目的紀錄，不屬於「四台」監看範圍，CLAUDE.md 規則「只寫入四台五字標欄位」已排除 B 欄。

資料列對應：五字標要填在對應分鐘的那一列，即 `F5:F64`／`J5:J64`／`N5:N64`／`R5:R64`（A5=1200 對齊第一列，A64=1259 對齊最後一列）。

## 4. example.xlsx 實際寫法分析（F/J/N/R 四個目標欄位的真實案例）

### 4.1 一般單則新聞
正常情況下，當某一分鐘該台切換到新的新聞主題時，才在對應那一列的五字標欄填入 5 個字左右的標題文字，例如：
- `F5 = '阿美麻糬亡'`
- `F7 = '追阿美麻糬'`
- `F10 = '談判砍男傷'`

字數大致是 5 個字，但不是強制剛好 5 字（例如下面的廣告/氣象是例外）。

### 4.2 同則延續（同一則新聞持續播出）
**實際寫法：留空，不重複填寫前一列的標題。**
觀察同一欄（例如 F 欄）：`F5`有值、`F6`空白、`F7`才出現下一則標題——代表 1200–1201 這段時間仍在播同一則（F5 的內容），直到下一個非空格子出現新標題才算換則。
全份範例中沒有看到任何「同上」、「↓」或重複文字的寫法，一律是「只在新則開始的那一分鐘填字，之後空著直到換則」。

範例片段（F 欄，TVBS-N）：
```
A5=1200  F5='阿美麻糬亡'
A6=1201  F6=(空白)        ← 同則延續
A7=1202  F7='追阿美麻糬'  ← 換則
A8=1203  F8=(空白)        ← 同則延續
A9=1204  F9=(空白)        ← 同則延續
A10=1205 F10='談判砍男傷' ← 換則
```

### 4.3 同分鐘多則（同一分鐘內有兩則不同新聞）
**實際寫法：兩則標題用斜線 `/` 相連，中間不加空格，依播出順序排列。**
範例：
- `F33 = '持刀警開槍/台股二補跌'`（TVBS-N，1208 這一分鐘內出現兩則）
- `J43 = '基議員徹選/韓輔選金句'`（東森，1238 這一分鐘內出現兩則）

### 4.4 廣告／非新聞區段
**實際寫法：直接寫該區段名稱的純文字，不必是 5 個字**，常見值：
- `廣告`（最常見，F/J/N/R 欄中出現的都是單純兩個字「廣告」，沒有編號或秒數）
- `氣象`（`R55 = '氣象'`，天氣預報區段）

值得注意：三立自己的 B 欄裡偶爾會看到 `廣告 2`、`廣告3`、`30秒廣告.` 這類帶編號/秒數/句點的寫法，那是三立內部備註習慣，**不屬於本次要填的 F/J/N/R 四欄規則**，四台欄位一律用最簡單的「廣告」二字即可。

### 4.5 三立（B 欄）的特殊標記（僅供參考，不在填寫範圍）
B 欄裡能看到幾種本任務不需要處理、但有助於理解範本邏輯的標記，列出備查：
- 標題後附加分鐘碼：`B7='追阿美麻糬1200'`、`B29='沈玉琳奪獎2400'` → 疑似標記「這則新聞最初出現的時間點」
- 製播時間前綴：`B31='(12製播)樊振東MLB'`、`B32='(06製播)冒全聯董座./(12製播)正妙歉跳電'` → 兩則不同時段製播的內容用 `/` 相連（跟 4.3 的多則寫法一致）
- 前綴字母：`B9='P談判砍男傷1200'`、`B39='OK(原音)沈說水文化1000'` → P、OK 等前綴意義未知，可能是主播/播出狀態標記
- 這些都只出現在 B 欄（三立自家紀錄），F/J/N/R 四欄範例中沒有出現過這類前綴或後綴，顯示四台欄位的寫法比三立自己的欄位單純。

## 5. 填寫規則總結

1. 只能寫入 `F5:F64`、`J5:J64`、`N5:N64`、`R5:R64` 這四欄（對應 TVBS-N / 東森 / 民視 / 華視），其餘儲存格（含收視率欄、B 欄、表頭、合併格式）不可更動。
2. 每列固定對應 1 分鐘（A 欄 1200–1259），一一對照影片時間軸。
3. 新則開始時才填字；同一則新聞持續播出的分鐘留空，不重複填寫。
4. 同一分鐘內有兩則不同新聞時，用 `前則/後則` 的格式（斜線相連、無空格）寫在同一格。
5. 廣告、氣象等非新聞區段，直接填入該區段名稱（如「廣告」「氣象」），不受 5 字限制，也不加編號或秒數。
